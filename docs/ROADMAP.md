# ORIEL Roadmap

## 0.7.x Stabilization

- Split monolithic interpreter into architecture modules
- Unified source spans and diagnostics
- Complete symbol table and type checker foundation
- Regression and fuzz tests
- Cross-platform CI
- Stable CLI behavior
- LSP diagnostics, completion and hover
- Reproducible wheel and VSIX builds

## 1.0 Console Stable

- Frozen language grammar and compatibility policy
- Stable interpreter/bytecode runtime
- Stable module and package model
- Standard library baseline
- Debugging and documentation tools
- Signed release artifacts and checksums

## After 1.0

- ORIEL API and database packages
- Web framework
- Desktop and mobile targets
- Data and AI frameworks
- Native compiler investigation
